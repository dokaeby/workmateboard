## 절차

1. 격리된 테스트 설정과 테스트 PostgreSQL을 준비한다.
2. 외부 LLM·Google·Push 호출은 mock/fake adapter로 대체한다.
3. 각 케이스의 유효/무효 입력과 상태 전이를 준비한다.
4. 단위 테스트를 실행하고 케이스 ID별 결과와 실패 로그를 보관한다.
5. 실패 시 관련 도메인 단위의 테스트만 고쳐 전체 회귀를 확인한다.

실제 OAuth 토큰, 회사 메일 원문, 실사용 Calendar 계정을 테스트 데이터로 사용하지 않는다. 시간 경계 테스트는 고정 clock 및 명시적 timezone을 사용한다.
