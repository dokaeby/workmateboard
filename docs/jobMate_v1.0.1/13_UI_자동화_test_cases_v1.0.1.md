## 자동화 구현 현황 (2026-11-19)

`tests/ui/test_dashboard.py`(pytest + Playwright chromium)가 아래를 자동 검증한다.
자세한 절차는 14번 문서 참조.

| ID | 자동화 | 비고 |
|---|---|---|
| UI-01 | 부분 | 실행 제출 폼은 있으나 로그인·템플릿 선택 UI 없음 |
| UI-02 | 부분 | 실행 이력 테이블·상세 패널 렌더링만 검증 |
| UI-03 | 미구현 | Google 연결 UI 없음 (CLI `jobmate google-auth`만 존재) |
| UI-04 | 부분 | 설정 다이얼로그 저장→API 반영 검증 |
| UI-05 | 부분 | 빈 상태 렌더링만 (실제 메일 감지 E2E는 fake integration 필요) |
| UI-06 | 미구현 | 실기기 push 권한 필요 |
| UI-07 | 부분 | VAPID 미설정 alert 경로만 검증 |
| UI-08 | 미구현 | 연결 해제 UI 없음 |
| UI-09 | 미구현 | 인증/멀티유저 미구현 |
| UI-10 | 부분 | 메뉴 전환만; 키보드 탐색·확대 미검증 |
