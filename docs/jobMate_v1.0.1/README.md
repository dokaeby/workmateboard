## MVP 기획 핵심

모델만으로 업무 성공을 정의하지 않는다. 가이드·결정적 센서·한도 있는 실행 루프·영속 메모리·최소 권한/예산·관찰가능성을 함께 제공한다. 기본기획서 8절은 계층별 MVP 적용과 완료 증거, 9절은 실패 개선 래칫을 정의한다. 02 시스템 상세설계서, 03 개발 로드맵, 12 테스트 가이드, 17 운영·보안 가이드는 해당 기준을 구현·검증·운영 단계로 구체화한다.

## MVP 핵심 일정 자동화 정책

명확하고 검증 가능한 일정 메일은 Calendar에 자동 등록한다. 등록 완료 후 웹 푸시를 보내며, 푸시를 선택하면 해당 원본 Gmail 메일을 연다. 일정이 모호하거나 반복 조건이 불명확한 경우는 자동 등록하지 않고 검토 대기한다. 푸시 권한이 없는 경우에도 자동 등록은 진행하고 앱 내 알림을 남긴다.
