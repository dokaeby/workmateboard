## 1. 개발 단계

### 1.1 기반·계약

- Django 프로젝트, PostgreSQL, 사용자·조직 권한 구조
- API 오류 형식, 상태 값, DB 마이그레이션 원칙 확정
- LangGraph 실행 골격, Langfuse trace 연계
- OAuth 동의·토큰 암호화·연결 해제 설계
- 가이드: 템플릿 완료 정의/금지 행동, 최소 실행 설정과 버전 고정
- 센서: 구조화 schema 검증 및 기존 권한 검사를 첫 결정적 gate로 연결

완료 증거: 로컬 환경에서 사용자 로그인, 샘플 workflow 실행 및 추적 조회가 가능하다.
재시작 후 동일 run을 이어서 처리하는 checkpoint 복구도 이 단계에서 확인한다.

### 1.2 업무 템플릿

- 회의록 정리, 문의 답변 초안, 주간 보고서 템플릿
- 실행 목록·상세, 단계 상태·결과, 승인 대기 UI
- 제한 재시도와 오류 복구

완료 증거: 대표 입력에서 세 템플릿의 정상·실패 흐름이 재현된다.

### 1.3 Gmail→Calendar 자동화

- Google OAuth 연결 및 최소 scope 검토
- Gmail 검색과 처리 cursor, 일정 추출·정규화
- Calendar 자동 등록 및 원본 메일 ID 기반 중복 방지
- 등록 성공 후 푸시 생성, 클릭 시 원본 Gmail 메일 이동

완료 증거: 중복 입력, 시간대가 다른 메일, 취소·철회 및 API 재시도 시 데이터가 일관된다.

### 1.4 파일럿·운영 준비

- 실제 사용자 승인으로 자동화 동작·권한 범위 검토
- 알림 권한 미허용, 푸시 실패, 만료 구독 처리
- 비용·지연·오류 대시보드와 보관 정책 확정
- 실행별 비용·시간·도구 호출 상한, 비상 정지와 운영 tripwire 설정
- 실제 실패를 가이드/센서/루프/메모리/권한/관찰 계층 중 하나로 분류하고 회귀 케이스화

## 2. 배포 게이트

- Google OAuth 검증과 허용 사용자 범위를 확인한다.
- 일정 자동 등록은 지정 파일럿 사용자부터 활성화한다.
- 일정 추출 오류와 중복 지표가 합의한 기준 안에 든 후 범위를 넓힌다.
- 롤백은 Gmail 감지 및 자동 등록 설정을 끄고, 이미 생성된 이벤트는 별도 정리 목록으로 제공한다.

## 3. MVP 완료 조건

기본기획서 7절의 완료 조건, API/DB 설계 계약, 단위·통합·UI 검수 항목을 모두 만족해야 한다. Google 연동 승인 또는 푸시 전달 같은 외부 조건은 환경별 제한과 관찰 가능한 대체 동작을 기록한다.

하네스 완료 조건은 기본기획서 8~9절을 따른다. 단순히 trace나 토큰을 남기는 것이 아니라 실행 결과와 외부 효과를 검증 가능한 증거로 연결해야 한다.
