6. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 열람·조회: 대시보드 설정 > 계정에서 본인 계정 정보와 처리된 데이터 확인
  • 정정·수정: 표시 이름 등 계정 정보를 설정에서 직접 수정
  • 삭제: 설정 > 계정의 계정 삭제 기능으로 계정 및 연동 데이터 삭제 요청 (법정 보존 의무 항목 제외)

  • 데이터 내보내기: 설정 > 계정의 데이터 내보내기(Export) 기능으로 본인 데이터 다운로드

8. 개인정보의 안전성 확보 조치

  • 비밀번호는 scrypt 해시로 변환하여 저장하며 원문은 보관하지 않습니다.
  • 세션 토큰은 SHA-256 해시만 저장하여 탈취 시 원본 토큰을 복원할 수 없게 합니다.
  • 관리자 권한과 일반 사용자 권한을 분리하고 감사 로그를 기록합니다.
  • 접속 로그·에러 로그·인증 로그·감사 로그를 기록하고 변조 방지를 위해 서버 외부로 전송·보관합니다.
  • 로그에 비밀번호·토큰·API 키·개인정보 원문 등 민감값을 기록하지 않습니다.
